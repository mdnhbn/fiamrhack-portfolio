## Coursework snapshot

Topics from the Arena Web Security AWS 66 Delta classes include SQL injection, XSS, file-upload risks, session security, LFI and path traversal concepts; Burp Suite, PortSwigger labs, Acunetix, Nuclei, and Nikto; OSINT and web reconnaissance; Linux and WordPress security; WAF/IDS concepts; and evidence-based reporting.

This course is in progress. The portfolio describes guided learning and authorized labs, not a certification or professional testing experience. The CyberNest archive marks the 15 November class recording as pending and notes missing video parts for report writing.
